# Pro vs Enterprise Features

The following is an overview of the QLM Management Console features that are only accessible to QLM Enterprise users. This list is not exhaustive.

| Feature                                                                                                                            | Description                                                                                                                                                                  |
| ---------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [Audit Trail](user-interface/manage-license-keys/audit-trail.md)                                                                   | The QLM Audit Trail keeps a record of operations performed on the server.                                                                                                    |
| [Analytics](../how-to/qlm-enterprise-analytics.md)                                                                                 | Analytics collects data about your application's usage.                                                                                                                      |
| [Computer Properties](../how-to/how-to-block-computers-from-activating-a-license.md)                                               | Properties that can be set to allow or deny activation to a list of computers                                                                                                |
| [Global Search](user-interface/manage-license-keys/global-search.md)                                                               | The Global Search feature performs a deep search looking for relationships between licenses and reports results found in multiple QLM tables.                                |
| [Advanced Filters](user-interface/manage-license-keys/advanced-filter.md)                                                          | The Advanced Filter feature allows you to perform searches based on QLM Features and QLM Product Properties values.                                                          |
| [Webhooks](../how-to/qlm-webhooks.md)                                                                                              | Webhooks settings allow you to control the behavior of webhooks processing.                                                                                                  |
| [Email Aggregation](../email-framework/email-notifications/send-aggregated-email-notifications-per-subscription-order-or-email.md) | When sending email notification reminders to your customers, you can configure the email to aggregate all licenses associated with a given subscription, order, or customer. |
| [Product Properties Expiry Dates](../how-to/product-properties.md)                                                                 | Allows you to set an expiry date on a product property                                                                                                                       |
| [License Binding Per Feature](../fundamental-concepts/variablelicensebinding.md)                                                   | Allows you to associate a binding method with a QLM feature.                                                                                                                 |
| White Listing IP Addresses                                                                                                         | List of white listed IP addresses that bypass any other property that blocks trial registration by IP Address.                                                               |
